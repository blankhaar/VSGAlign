# VSGAlign

VSGAlign provides continuum, polarized, and discrete-reference calculations
for spinning-dust emissivity and absorption cross sections. It accompanies
the paper [*A quantum theory of the alignment and polarization of very small
dust grains*](https://arxiv.org/abs/2604.26001).

The supported workflows are:

- compute emissivity and polarized emissivity for individual grains;
- compute continuum absorption cross sections;
- validate the continuum approximation against the discrete reference model;
- reproduce the two VSGAlign emissivity figures used in the final manuscript.

## Install

For a development checkout with tests and figure generation:

```bash
python -m pip install -e ".[dev]"
```

For a lighter install without plotting tools:

```bash
python -m pip install -e .
```

To build release artifacts locally:

```bash
python -m pip install -e ".[release]"
python -m build
```

## Quickstart

```python
import numpy as np

from vsgalign import (
    DustGrain,
    jnu_total,
    jnuq_total,
    polarized_params_from_dust,
    rotor_params_from_dust,
    sigma_nu_total,
)

grain = DustGrain(a_eff=5e-8, T_gas=100.0)
nu = np.linspace(1e9, 80e9, 200)

params = rotor_params_from_dust(grain)
pol_params = polarized_params_from_dust(grain, chi=np.pi / 2)

intensity = jnu_total(nu, params)
polarized = jnuq_total(nu, pol_params)
cross_section = sigma_nu_total(nu, params)
```

All three outputs have the same shape as `nu` and are finite for this example.
The emissivities use CGS units with the rotor number density carried by
`params.n`; the cross section is in `cm^2`.

The specialized scientific packages remain importable under descriptive names
such as `rotor_emissivity`, `rotor_polarized_emissivity`, and
`rotor_cross_section`. New user code should prefer the `vsgalign` facade.

## Command line

The command-line interfaces use the same CGS convention as the Python API.
Dipole components are supplied in `esu cm`:

```bash
vsgalign-emissivity eval --nu 3e10 --mu-par 1e-18 --mu-perp 1e-18
vsgalign-polarized-emissivity eval --nu 3e10 --sigma 0.1 --chi 1.570796
```

Run either command with `--help`, or a subcommand followed by `--help`, for all
parameters and units.

## Reproduce the manuscript figures

For the exact environment used in release validation:

```bash
python -m venv .venv-reproduction
source .venv-reproduction/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements/reproduction.txt -e .
python -m paper.reproduce_all --output-dir reproduced-figures
```

The default workflow generates the single-grain and size-distribution figure
families. Their combined PDFs, `single_grain_combined_a5.0.pdf` and
`size_dist_combined.pdf`, are the two VSGAlign outputs used in the final
2026-08-04 A&A revision-3 submission. That submission, not arXiv v1, defines
the accepted figures. Reference hashes and provenance are recorded in
[paper/REFERENCE_FIGURES.md](paper/REFERENCE_FIGURES.md).

Two additional cross-section workflows are retained as diagnostics but were
not included in the final manuscript. Generate them explicitly with:

```bash
python -m paper.reproduce_all --include-diagnostics
```

The manuscript-specific grain-angle schematic and ground-state-alignment PNG
are not generated by VSGAlign. See [docs/paper_figures.md](docs/paper_figures.md)
for the exact support boundary.

## Validation visuals

For non-paper visual inspection of continuum-versus-discrete agreement:

```bash
python -m validation.continuum_vs_discrete --output-dir artifacts/validation
```

This writes a compact comparison plot and JSON metrics into the ignored
`artifacts/` tree.

## Run the tests

```bash
pytest -q
```

The suite covers component behavior, continuum/discrete regression checks,
the public API, command-line units, and lightweight figure workflows. It is
grouped into `tests/unit/`, `tests/regression/`, and `tests/workflows/`.

## Repository layout

- `src/dust_properties/`: grain model and rotational-temperature logic
- `src/spindust_trot/`: single-temperature spinning-dust support code
- `src/rotor_emissivity/`: unpolarized continuum emissivity
- `src/rotor_polarized_emissivity/`: polarized continuum emissivity and alignment bridge
- `src/rotor_cross_section/`: continuum absorption cross sections
- `src/discrete_emissivity/`: discrete reference calculation for validation
- `paper/`: maintained manuscript-figure and diagnostic workflows
- `validation/`: lightweight non-paper convergence and inspection plots
- `tests/`: unit, regression, and workflow checks
- `docs/`: architecture, figures, testing, and release guidance

## Canonical and validation code

The package-level API exports the canonical continuum path:

- `rotor_emissivity.impl_b` for unpolarized emissivity;
- `rotor_polarized_emissivity.continuum_impl_b` for polarized emissivity.

The `impl_a` variants and `discrete_emissivity` remain independent validation
paths rather than alternative public APIs.

## Units

Internal calculations use CGS units:

- dipole moments: `esu cm`;
- frequencies: `Hz`;
- temperatures: `K`;
- emissivities: CGS, including the number density supplied in `params.n`;
- cross sections: `cm^2`.

See [docs/architecture.md](docs/architecture.md),
[docs/paper_figures.md](docs/paper_figures.md), and
[docs/testing.md](docs/testing.md) for more detail.
